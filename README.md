# EventLens AI — Cloud Event Photo Distribution & AI Face Search Platform

An enterprise-grade, high-performance web platform built for event photography businesses to easily share 200+ high-resolution photos per event, generate venue QR codes, and allow attendees to instantly locate every photo they are in using client-side AI face recognition.

---

## ✨ Features

- **⚡ AI "Find My Photos" Matcher**: Attendee snaps a selfie or uploads a picture; lightweight neural networks detect and match faces in 1.5s with zero GPU server upkeep.
- **📸 200+ Bulk Photo Uploader**: Multi-file batch drag & drop with concurrent upload streams, thumbnail generation, and real-time face indexing.
- **📱 Venue QR Codes**: 1-click printable / shareable QR codes for table standees and lanyard badges.
- **💎 Lossless High-Res Downloads**: Full-resolution single downloads and multi-photo batch ZIP packaging.
- **🌐 Cloud Ready**: Designed for 1-click Vercel & Supabase cloud deployment.
- **🎨 Luxury Aesthetics**: Dark glassmorphic design system with responsive mobile-first optimization.
